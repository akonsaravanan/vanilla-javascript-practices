# HackerRank DOM JavaScript Practice Pack by Difficulty

This pack is designed for **HackerRank-style DOM JavaScript practice**.
It is organized into **Easy**, **Medium**, and **Hard** levels.

## What each task contains
- `task.md` → problem statement and requirements
- `index.html` → the fixed HTML you work with
- `styles.css` → base styles already provided
- `script.js` → write your JavaScript solution here
- `run-tests.html` → open this file in a browser to validate your solution
- `test.js` → unit tests that mark your code as pass/fail

## How to practice
1. Open a task folder.
2. Read `task.md`.
3. Write your solution in `script.js`.
4. Open `run-tests.html` in a browser.
5. Check the result summary on the page.
