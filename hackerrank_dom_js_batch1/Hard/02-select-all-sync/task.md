# Hard - Select All Sync

## Goal
Write JavaScript so that:
1. Checking `Select All` selects all item checkboxes.
2. Unchecking `Select All` clears all item checkboxes.
3. Unchecking any single item also unchecks `Select All`.
4. If all individual items are checked manually, `Select All` becomes checked.
5. Update `#selected-count` with the number of selected items.
