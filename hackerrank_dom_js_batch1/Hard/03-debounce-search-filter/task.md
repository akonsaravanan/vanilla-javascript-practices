# Hard - Debounce Search Filter

## Goal
Write JavaScript so that:
1. Typing in the search box filters the list **after a 300ms debounce**.
2. Matching must be **case-insensitive**.
3. Non-matching items should be hidden.
4. Clearing the input should show all items again.

## Important
Do not filter immediately on every keystroke. Wait until typing stops for 300ms.
