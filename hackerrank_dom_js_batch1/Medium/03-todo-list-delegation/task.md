# Medium - Todo List Delegation

## Goal
Write JavaScript so that:
1. Clicking `Add` inserts a new `<li>` inside the list.
2. Empty or whitespace-only values must be ignored.
3. Clicking a todo text toggles a `done` class on that item.
4. Clicking the item's `Delete` button removes that item.

## Hint
This task is ideal for **event delegation**.
