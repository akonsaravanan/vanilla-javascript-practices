# HackerRank DOM JS Practice Pack

This pack contains DOM-focused JavaScript practice tasks similar to HackerRank frontend questions.

## Included tasks
- accordion
- tabs
- dropdown
- select-one
- faq-toggle
- counter
- modal
- todo

## How to use
1. Open a task folder.
2. Run `index.html` in a browser.
3. Implement the logic in `script.js` only.
4. Use `test.js` as a guide for what unit tests may validate.

## Recommended order
1. accordion
2. tabs
3. select-one
4. dropdown
5. faq-toggle
6. counter
