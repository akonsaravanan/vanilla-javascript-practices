# HackerRank DOM JS Practice - Batch 2

This is a second set of DOM-focused vanilla JavaScript tasks for practice.
Each task contains:
- `task.md`
- `index.html`
- `styles.css`
- `script.js` (you solve here)
- `test.js`
- `run-tests.html`

## Levels
### Easy
1. show-hide-password
2. character-counter-limit
3. image-gallery-switcher

### Medium
1. star-rating
2. otp-input-navigation
3. dismissible-alerts

### Hard
1. autocomplete-suggestions
2. pagination-list
3. editable-todo-list

## How to use
1. Open any task folder
2. Read `task.md`
3. Implement logic in `script.js`
4. Open `run-tests.html` in browser
