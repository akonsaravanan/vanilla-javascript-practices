# Vanilla JS Phone Directory Practice

A HackerRank-style **vanilla JavaScript DOM challenge** to practice:
- form validation
- dynamic table rendering
- searching/filtering
- sorting by name

## Folder structure
- `src/index.html` → fixed HTML structure
- `src/styles.css` → base styling
- `src/script.js` → **write your solution here**
- `tests/phone-directory.test.js` → unit tests
- `question.md` → problem statement and exact requirements
- `package.json` → test dependencies/scripts
- `jest.config.js` → Jest config

## How to run locally
1. Extract the zip.
2. Open a terminal in the project folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run tests:
   ```bash
   npm test
   ```

## Notes
- Do **not** change the HTML ids/classes/testids unless you also update tests.
- Implement only in `src/script.js`.
